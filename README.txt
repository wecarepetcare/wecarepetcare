BEFORE PUBLISHING
1. Open script.js.
2. Replace YOUR-EMAIL@example.com with the email that should receive booking requests.
3. Open index.html to preview.

FREE PUBLISHING WITH GITHUB PAGES
1. Create a free GitHub account.
2. Create a public repository named wecarepetcare.
3. Upload index.html, styles.css, script.js and the assets folder.
4. Go to Settings > Pages.
5. Select Deploy from a branch, choose main and /root, then Save.
6. GitHub will give you a free address like:
   https://yourusername.github.io/wecarepetcare/

GOOGLE SITES
Google Sites cannot upload this HTML directly. Once the site is published:
Insert > Embed > By URL > paste the GitHub Pages address.
For the best result, use the GitHub Pages address as the main website.
